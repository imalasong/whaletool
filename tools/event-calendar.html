数据来源 fantopia.io/fanapiWeb/eventsInfo/getEventsInfoPageV2 —— 服务端可能有 3 分钟缓存，刷新拿到的未必是毫秒级最新。

上架地区 接口按请求头 area 只返回该地区上架的活动，各地区的活动池并不互相包含（实测 area=MY 有 101 条在 area=MO 视角下不存在）。不传 area 时等同 area=MO。选「全部地区（合并）」会并发请求 10 个地区并按活动 id 去重，故耗时与流量都会明显增加。

状态取值 sellStatus 实际枚举为 0 待开始(待开售) / 1 进行中 / 2 已售罄 / 3 已结束 / 4 缺货登记；本页默认只取 0。

时间口径 sellDateTime 为北京时间（服务端 siteTimeZone = +08:00）。开售时间显示 2099 年的场次，代表该活动暂无公开场次、开售时间未定。
