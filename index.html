🛠 怎么往这个合辑里加新工具？

1. 把工具页面丢进 tools/ 目录（单个 HTML 文件就行，自包含最好）；
2. 打开 assets/tools.js，在 TOOLS 数组里加一条记录：
   { id, name, desc, icon, href: "tools/xxx.html", tags: [], category, badge }
3. 刷新页面即可，卡片、搜索、分类计数都会自动更新。
